# Release `dll-2026-11-05` against `dll-2026-11-01`

**Compare for yourself:** [exact and lossy](../exact-vs-lossy.md) · [eight upscalers in test scenes](../upscaler-comparison.md) ·
[recorded game clips, side by side](https://zgauthier2000.github.io/fsr4-upscaler-compare/)

## What's new

Only the two Lite builds change. **`exact` and `lossy` are the same files as in `dll-2026-11-01`, byte for byte.** There is no picture to show: the gain is speed.

- **Faster at 1440p and 800p on every GPU that measured them:** RX 7000, RX 6000, the Steam Deck and the Steam Machine (800p: RX 6000 and the Steam Deck, whose screen size it is). Both Lite builds gain most at these two sizes (figures below).
- **A few dispatches less per frame:** passes that do no work for the picture are no longer started. This is the 1 to 3% at 1080p and 4K.
- **`4.1.2l-exact`: one form for all four archives.** It shares color samples between pixels everywhere now, the Steam Deck / older built-in graphics archive
  included: in its own form it is still faster there.
- **`4.1.2l-lossy` for RX 7000 no longer shares color samples between pixels.** The other three archives carry the RX 6000 form (shared color samples and finished
  results in shared memory). Under Linux (Proton) on an RX 7800 XT that form needs more registers than RX 7000 keeps for a full load of work, and in Shadow of the Tomb Raider
  it rendered 2.4% fewer frames than `dll-2026-11-01`'s; the RX 7000 archive's build rendered 2.3% more ([game test](#game-test)). Same picture as the other archives'
  `4.1.2l-lossy`, byte for byte. On Windows RX 7000 one report so far (RX 7600): 0.3 / 0.5 / 0.7% faster than the RX 6000 form at 1080p / 1440p / 4K. The RX 7000 `4.1.2l-lossy` figures from Windows reports below are of the RX 6000 form.

**What got worse:** nothing slower beyond the spread of single runs. `4.1.2l-exact` on a Radeon 780M / Ryzen Z1 at 1080p measured 1.7% slower (two Linux reports), and `4.1.2l-lossy`'s RX 6000 form does not gain on Windows RX 7000 at 1080p and 4K (0.0%). The RX 7000 archive's `4.1.2l-lossy` has one Windows RX 7000 report so far (RX 7600, 0.3 to 0.7% faster than the RX 6000 form); on Windows RX 6000 cards that build is 1 to 2% slower (why those keep the RX 6000 form).
