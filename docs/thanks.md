# Thank you

[Back to the front page](../README.md)

This project depends on people who run it on their own machines and say what they see. Timing-kit
reports from graphics cards the author does not own, videos of things that look wrong, and
side-by-side comparisons in games have found most of what the releases since the first one fixed.
Every report is a valued part of this project, including the many sent without a name.

## How to be listed, or taken off

- Run a [timing kit](../timing-kit) and type a name or nickname when it asks.
- Only names typed into that question are listed. Nothing is taken from Discord, GitHub or anywhere else.
- Vulgar or offensive names are left out.
- To have a name changed or removed, open an issue on the project's GitHub page.
