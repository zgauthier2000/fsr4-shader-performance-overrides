Which games should this project test with?

This project makes faster FSR 4 builds and, as an experiment, cleaner ones. Pictures from real games decide whether a change looks better or worse, so the games we record matter. Vote for the games you would most like to see tested. The most-voted ones are the first to be installed, recorded as short test clips and compared, and some may also be used to train the cleaner builds.

This is a wish list, not a promise: a game is only used if it works for the project (see below) and the author can get it.

If the poll does not show here, open it on StrawPoll.

What a game needs

  • DirectX 12, with an upscaler that OptiScaler can switch to FSR 4 (games with FSR 3.1, DLSS or XeSS usually work). Games that run only on Vulkan or older DirectX can't use this project's builds.
  • It runs under Proton on Linux, the author's system.
  • Single-player, or a mode without online play: games with kernel anti-cheat are left out.
  • Scenes that are hard for an upscaler help most: grass and leaves, hair, rain and sparks, thin wires and railings, water, fast camera motion.

Already used

  • Shadow of the Tomb Raider
  • Black Myth: Wukong Benchmark Tool
  • Stellar Blade demo

Your vote and your data
