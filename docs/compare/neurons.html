One student, two teachers: Lite and full FSR 4

This project is training a cleaner FSR 4.1.2 Lite: the same small network as AMD's Lite, taught to fix the places where Lite looks worse than AMD's full FSR 4, such as fine patterns that crawl, while keeping what Lite already does well. Here the networks are drawn as neurons. It would not be AMD's picture, so it would be neither exact nor lossy, and it is not in any release.

  1. A test frame arrives.

    The frames come from test scenes made on purpose, so the true, perfect picture is known for every one: rain, foliage, wires, fades, fine patterns.

  2. Both teachers answer.

    AMD's own Lite and AMD's full FSR 4 each upscale the same frame. Neither is perfect, and each is better in different places.

  3. Pixel by pixel, the closer teacher wins.

    Each pixel's target comes from whichever teacher is closer to the true picture there. So the student learns from full FSR 4 where Lite crawls, and from Lite where Lite is already better.

  4. The student answers.

    The student is Lite's own network, started from AMD's Lite weights, so it begins as Lite. It runs on every frame, like AMD's Lite.

  5. The difference flows back.

    Where the student's pixels miss the target, the miss travels backward through its neurons and says which connections caused it.

  6. Connections change, a little.

    Each step nudges the connection strengths only slightly. The latest runs change about one in a hundred of the network's stored values in a whole run. Bigger steps undid earlier gains.

  7. Memory loops back.

    The network keeps part of each frame as history for the next. How much it keeps decides how fast it follows a brightening scene and whether moving objects leave outlines, so training watches that too.

Then the checksTraining alone proves nothing. Every saved version goes through dozens of test scenes against rules set before the results, and through frames recorded from real games. The current runs work on still scenes, where thin lines such as wires shimmer more than in AMD's Lite.
